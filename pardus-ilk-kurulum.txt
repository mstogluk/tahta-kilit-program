PARDUS MAKİNESİNDE BİR KERELİĞİNE ÇALIŞTIRILACAK KOMUTLAR
============================================================

Bu dosyayı Pardus makinesine bir şekilde ulaştır (USB, e-posta, vs.)
ya da içeriğini kopyalayıp Pardus'taki terminale yapıştır.

Aşağıdaki komutları TEK TEK, sırayla çalıştır. Kod klasörünün yolu
farklıysa (/opt/tahtakilit değilse) ilk satırdaki yolu değiştir.

------------------------------------------------------------
0) Git kurulu değilse (ilk komut "git: komut bulunamadı" derse):
------------------------------------------------------------
sudo apt update && sudo apt install -y git

(etapadmin şifresini soracak)

------------------------------------------------------------
0.5) "erişim engellendi" / permission denied hatası alırsan:
------------------------------------------------------------
(/opt/tahtakilit klasörü root'a ait olabilir, önceki sudo kurulumdan
kalma — sahipliği kendi kullanıcına al)

sudo chown -R $(whoami):$(whoami) /opt/tahtakilit

------------------------------------------------------------
cd /opt/tahtakilit
git init -b main
git remote add origin https://github.com/mstogluk/tahta-kilit-program.git
git pull origin main
chmod +x github_gonder.sh github_al.sh
------------------------------------------------------------

Not: "git pull origin main" komutu sana GitHub kullanıcı adı ve
şifre soracak. Şifre yerine bir "Personal Access Token" (PAT)
girmen gerekiyor (GitHub artık düz şifre kabul etmiyor).

Token oluşturmak için:
1. Tarayıcıda (herhangi bir bilgisayarda) github.com'a giriş yap.
2. Sağ üstteki profil fotona tıkla > Settings
3. En altta sol menüde: Developer settings
4. Personal access tokens > Tokens (classic) > Generate new token (classic)
5. "repo" kutucuğunu işaretle, süre seç (örn. 90 gün ya da No expiration)
6. Generate token'a bas, çıkan uzun kodu KOPYALA (bir daha gösterilmiyor!)
7. Pardus terminalinde şifre sorduğunda bu kodu yapıştır (kullanıcı adı
   olarak yine GitHub kullanıcı adını gir: mstogluk)

Bu token'ı bir yere not al, her push/pull'da tekrar tekrar sorulmaması
için Pardus'ta şu komutla bir kereliğine kaydedebilirsin:
------------------------------------------------------------
git config --global credential.helper store
------------------------------------------------------------
(Bu satırı yukarıdaki 5 komuttan ÖNCE çalıştırırsan, ilk girdiğin
token diskte düz metin olarak saklanır ve bir daha sorulmaz.)

------------------------------------------------------------
DAHA KALICI ÇÖZÜM: SSH ANAHTARI (token hatırlamana hiç gerek kalmaz)
------------------------------------------------------------
Token'ı unutma/kaybetme derdi olmasın istersen SSH anahtarı kur:

1) Anahtar üret (her soruya Enter'a basıp geçebilirsin):
       ssh-keygen -t ed25519 -C "mstogluk@gmail.com"

2) Açık anahtarı göster:
       cat ~/.ssh/id_ed25519.pub

3) Çıkan satırı kopyala. GitHub'da: profil fotosu > Settings >
   sol menüde "SSH and GPG keys" > "New SSH key" > yapıştır > Add SSH key

4) Repo adresini SSH'a çevir:
       git remote set-url origin git@github.com:mstogluk/tahta-kilit-program.git

5) Test et:
       ssh -T git@github.com
   "Hi mstogluk! ..." yazısı görürsen tamamdır.

Bundan sonra git push/pull hiçbir şey sormaz.

------------------------------------------------------------
İLK KURULUM BİTTİKTEN SONRA, HER SEFERİNDE:
------------------------------------------------------------
Kod değişikliklerini GitHub'a göndermek için:
    ./github_gonder.sh

Windows tarafında değişen bir şeyi Pardus'a çekmek için:
    ./github_al.sh


============================================================
CLAUDE DESKTOP'I PARDUS'A KURMAK (bir kereliğine)
============================================================

NOT: Bu adımlar İNTERNET gerektirir. Debian 12 (bookworm)+ / Ubuntu
22.04+ gerekiyor — Pardus ETAP23, Debian 12.3 tabanlı olduğu için
uyumlu (doğrulandı, 2026-09-16).

Sudo/admin (etapadmin) şifresi istenecek — apt deposu eklemek için.

------------------------------------------------------------
1) Anthropic'in resmi apt deposunu ekle ve kur:
------------------------------------------------------------
sudo curl -fsSLo /usr/share/keyrings/claude-desktop-archive-keyring.asc https://downloads.claude.ai/claude-desktop/key.asc
echo "deb [signed-by=/usr/share/keyrings/claude-desktop-archive-keyring.asc] https://downloads.claude.ai/claude-desktop/apt/stable stable main" | sudo tee /etc/apt/sources.list.d/claude-desktop.list
sudo apt update && sudo apt install claude-desktop

------------------------------------------------------------
2) Aç ve giriş yap:
------------------------------------------------------------
Uygulamalar menüsünden "Claude" ara, ya da terminalde:
    claude-desktop

İlk açılışta seni giriş yapmaya yönlendirecek — Windows'taki Claude
Code'da kullandığın hesapla (aynı e-posta) giriş yap.

------------------------------------------------------------
3) Güncelleme:
------------------------------------------------------------
Normal sistem güncellemesiyle birlikte gelir:
    sudo apt update && sudo apt upgrade

------------------------------------------------------------
