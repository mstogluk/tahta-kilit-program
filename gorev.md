# Görev Kutusu

Windows tarafından Pardus tarafına (Claude Code) iletilecek görevler buraya yazılır.

## Kullanım
- Windows: Buraya görevi ekle, `github_gonder.bat` ile push et.
- Pardus: `git pull` sonrası bu dosyayı oku, görevi yap, satırın başındaki `[ ]`'ı `[x]` yap, sonucu maddenin altına kısa not olarak ekle, `git push` et.

## Bekleyen görevler

- [ ] (örnek) İlk gerçek görev buraya yazılınca bu satır silinecek.
